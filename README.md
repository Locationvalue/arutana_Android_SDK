# Arutana 広告SDK Android

## Release Notes

### 2025-08-20: 0.1.4

- Advertising ID取得機能追加
- 動画広告コールバック追加

### 2025-04-14: 0.1.3

- モーダル広告において、広告枠を高速かつ連続的にタップした場合に、アプリ内ブラウザが複数立ち上がる問題を修正.

### 2025-03-13: 0.1.2

- 動画広告のfailedToReceiveAdコールバックの実行時に、極稀に例外が発生しアプリがクラッシュする問題を修正. 当該の問題が発生している場合はSDKをアップデート頂くことにより改善する可能性があります. この修正による実装の変更は必要ありません.

### 2024-12-26: 0.0.24

- モーダル広告にて、広告タップ時にarutanaInterstitialCloseイベントが呼ばれるタイミングを修正. 従来タップ時に呼ばれていたが、内部ブラウザを閉じた際に呼ばれるように変更.
- 特定の条件下でフリークエンシーコントロールが正常に動作しない不具合を修正.
- 上記の修正に伴い、ArutanaIntersitialAdクラスにonResume, onPauseメソッドを追加し、実装マニュアルを更新.

### 2024-10-29: 0.0.22

- モーダル広告の `setWidth()` が効かない問題を修正
